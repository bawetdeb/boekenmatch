# BoekenMatch – Codex startproject

## Wat je doet
1. Pak deze ZIP uit.
2. Open de map in Codex of VS Code met Codex.
3. Open `CODEX_INSTRUCTIONS.md`.
4. Geef Codex precies deze opdracht:

> Lees CODEX_INSTRUCTIONS.md volledig en voer Fase 1 uit in deze projectmap. Werk daadwerkelijk in de bestaande bestanden, test de app en los fouten op voordat je klaar bent.

## Lokaal testen
Het makkelijkst is met VS Code Live Server. Of start in deze map:

```bash
python -m http.server 8000
```

Open daarna `http://localhost:8000`.
